# Private production release v3

## Outcome

This release moves Understand Karachi from a district-led prototype to a
traveller-first mental map. It ships the Understand Karachi identity,
interactive globe, the `MODE → GATE → SPINE → HUB → LOCAL` crossing grammar,
mode-aware example crossings, selectable map details, Roman Urdu default with
English parity, bounded one-shot location estimation, and the civic project
documentation baseline.

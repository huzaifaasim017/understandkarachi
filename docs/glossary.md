# Product and Karachi glossary

Use these meanings consistently in data, copy, specs, and reviews. A familiar
name may overlap multiple administrative layers; the guide must state which
meaning is intended.

| Term | Meaning in this project | Usage rule |
| --- | --- | --- |
| Anchor | A memorable reference used to orient nearby places, such as Tower, Saddar, Airport, or Sohrab Goth | Never imply that an anchor is an administrative unit |
| Arabian Sea / sea | Karachi's southern orientation edge | Teach it before compass-dependent crossings |
| Cantonment | A separately administered military-area jurisdiction that can overlap familiar locality language | Do not equate it with a district or neighbourhood |
| Chowk | A junction or public square | Keep the proper name unchanged |
| Chowrangi | A major junction, historically often a roundabout | Treat as a landmark, not a district |
| Corridor / spine | A simplified city-scale movement axis joining major anchors | Not an exact routable path |
| Crossing grammar | `MODE → GATE → SPINE → HUB → LOCAL`, the reusable order for explaining a city-scale crossing | Direction is checkpoint context; a current-condition check is the final handoff, not another stage |
| District | One of the seven large administrative containers in Karachi Division | Always distinguish it from its familiar or historic names |
| Division | The administrative frame containing the seven Karachi districts | Use “Karachi Division” when citing division totals |
| Gateway | A major arrival, departure, or transfer point: airport, intercity rail, port, motorway, or regional exit | State its broad direction and connected corridor; an internal `GATE` checkpoint may instead mark a recognizable start or finish |
| Hub | A recognizable junction or transfer point used to confirm or change the city-scale direction | Do not imply that every hub is an official station or administrative unit |
| Landmark chain | Ordered landmarks used in spoken directions | Preserve travel order with arrows |
| Last mile | The final local segment after leaving a city-scale corridor | Requires an exact address, pin, sign, or current local guidance |
| Mental map | A simplified model of directions, anchors, layers, and connections a learner can reuse | Core product outcome |
| Mode | The selected travel mode: bike, car, or transit | Choose it before showing eligible crossing examples; do not infer legal access |
| Mor | A turn or bend used as a place name | Do not translate the proper name |
| Naka | A checkpoint, gate, or locality marker | Explain on first use if needed |
| Neighbourhood / area / ilaqa | A familiar local place below or across administrative layers | Pair with block, road, landmark, and pin for an address |
| Phatak | A railway crossing or gate | Treat as a landmark; current crossing conditions may differ |
| Pul | A bridge or flyover landmark | Do not assume it uniquely identifies an address |
| Route | In this project, use only for an explicitly sourced transport service or an external live-navigation result | Use “corridor” or “example journey” for schematic teaching lines |
| Schematic | Intentionally simplified geometry that teaches relationship, not survey precision | Display a visible limitation near relevant map use |
| Subdivision | An official unit below a district as represented by the cited administrative source | Do not silently substitute everyday town boundaries |
| Town | A context-dependent administrative, historic, or familiar name | Qualify the period or governing scheme when making an official claim |

## Naming examples

- “Malir” can mean a district, a broad familiar area, or a landmark such as
  Malir 15 or Malir Halt. Ask for context.
- “Korangi” can mean the district or a neighbourhood/industrial area within a
  broader south-eastern belt.
- “Keamari” can refer to the district, neighbourhood, harbour area, or a
  gateway context.
- “Guru Mandir” is a landmark/locality reference, not a district.
- “Karachi Port” and “Port Qasim” are separate ports in different parts of the
  city-region.

Add a term here only when it changes how contributors model or explain the
city. Localized short definitions used on screen remain in
`app/karachi-i18n.ts` and must preserve these meanings.
